# PCB — exports de fabricación

Exports de fabricación (capas etch/copper/mask/silk en PDF, y SVG) para la PCB v2, generados desde los proyectos Fritzing en la raíz de este repo (`Main PCB - Estación Meteorológica - IoT_v1.4.fzz`, `Aux PCB - Estación Meteorológica - IoT_v1.2.2.fzz`).

Fabricadas caseramente: PCB FR4 simple faz, transferencia de tóner + cloruro férrico. Ver `../componentes_y_conexiones.md` → "PCB v2 — en fabricación" para el estado del armado y el layout completo (asignación de holes, GPIOs, conectores JST).

- `Main 1.4/` — placa principal (ESP32, INA219×2, step-up boost, switching de rails).
- `Aux 1.2/` — placa auxiliar de conectores JST.
- `Main 1.4/Intento1/`, `Main 1.4/Intento2/` — iteraciones sucesivas del export de fabricación de la placa principal.
